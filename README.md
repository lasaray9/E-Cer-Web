ระบบเกียรติบัตรโรงเรียน
ช่วยให้การจัดทำเกียรติบัตรสำหรับนักเรียนสะดวกขึ้น ตั้งแต่เตรียมรายชื่อ กำหนดโครงการ ใส่พื้นหลังและลายเซ็น ไปจนถึงเลือกพิมพ์เกียรติบัตรหลายคน โดยไม่ต้องแก้ชื่อบนแบบทีละใบ

ระบบออกแบบสำหรับคุณครู เจ้าหน้าที่โรงเรียน และนักพัฒนาที่ต้องการนำไปศึกษาและต่อยอด หน้าจอภาษาไทย พัฒนาด้วย PHP 8, MySQL และ SweetAlert2

🎓 ฟังก์ชันหลัก

• จัดการโครงการและกิจกรรม แยกรายชื่อนักเรียนแต่ละโครงการ
• ระบุชื่อโรงเรียน ชื่อโครงการ ข้อความรับรอง และวันที่มอบเกียรติบัตร
• เพิ่มรายชื่อทีละคน หรือคัดลอกจาก Excel พร้อมข้อมูลห้องเรียน
• แก้ไข ลบ และค้นหารายชื่อนักเรียน
• อัปโหลดพื้นหลังเกียรติบัตร PNG หรือ JPG
• ใส่ภาพลายเซ็น ชื่อ และตำแหน่งผู้ลงนาม
• ปรับตำแหน่งแนวตั้งของข้อความ ขนาดชื่อ และสี พร้อมดูตัวอย่าง
• ใช้กรอบสีทองที่มีให้ หรือเลือกพื้นหลังของโรงเรียนเอง
• สร้างเลขที่เกียรติบัตรไม่ซ้ำ
• เลือกพิมพ์รายคนหรือหลายคน ครั้งละสูงสุด 100 คน
• บันทึกเป็น PDF ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์ ขนาด A4 แนวนอน

🛠️ การติดตั้งเบื้องต้น

แตกไฟล์โปรเจกต์ลงในโฟลเดอร์ htdocs ของ XAMPP หรือ www ของ Laragon
เปิด Apache และ MySQL
นำเข้าไฟล์ database.sql ผ่าน phpMyAdmin
ตั้งค่าการเชื่อมต่อฐานข้อมูลใน config.php
เปิดระบบผ่าน localhost แล้วเริ่มสร้างโครงการ

ไม่ต้องติดตั้ง Composer หรือ npm โดยมีรายละเอียดเพิ่มเติมใน README.md ภายในโปรเจกต์

📌 ขอบเขตของรุ่นนี้

ระบบใช้งานบนเครื่องที่ติดตั้งผ่าน localhost ยังไม่มีระบบล็อกอิน รองรับผู้ลงนาม 1 คนต่อโครงการ และใช้ภาพลายเซ็นสำหรับแสดงบนเกียรติบัตร หากต้องการเปิดใช้งานออนไลน์ ควรเพิ่มระบบยืนยันตัวตนและกำหนดสิทธิ์เข้าถึงข้อมูลก่อน

ก่อนนำไปใช้กับงานจริง ควรทดลองด้วยข้อมูลตัวอย่าง ตรวจชื่อ วันที่ ลายเซ็น และการจัดวางใน PDF ให้ครบถ้วน // แต้งภาพให้ดูมืออาชีพ จะลงเว็บ

ดาวน์โหลดไปทดลองใช้งาน เรียนรู้โครงสร้าง และพัฒนาต่อยอดให้เหมาะกับงานของคุณได้เลย
